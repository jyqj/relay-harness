## Source records and URL navigation

Library 的输出来源和 Work 活动打开只读 `record` 页，不再隐式打开或恢复对话。`#relay/record/<encoded-session-id>` 定位来源；官方 conversation、Work、Library 视图也参与浏览器历史。无效路由保持无效，URL 导航不授予权限、不激活 Session。只有显式进入对话的操作调用既有交互路径，委派记录通过其所有者进入。

记录读取绑定路由、页面激活状态和连接 epoch。隐藏、断线或被替代的读取会取消，迟到结果不能覆盖其他来源。历史分页保留前缀绑定的观察。Goal 阶段、执行、恢复能力、来源切点和覆盖缺口分别显示。该页面不是第二套任务存储、全局审批 Inbox、内容版本验收系统或 provider 健康仪表盘。活 Work 的确认核验使用不激活执行的 `workResults/review`。
# Client Product Shell

[English](README.md) | 中文

Chat、Work、Library 占据中央工作区。产品导航贡献到 `sidebar.primary`，三个视图中都保留工作区浏览、会话搜索和新建会话。Work 与 Library 注册到 [ui-layout](../ui-layout/README.md) 拥有的 keyed `shell.page`；它们不替换 conversation slot，也不创建第二个对话渲染器。

## 中央工作区

切换主页面时 Chat 保持挂载；访问过的主页面也保持挂载并接收 `active`。隐藏页面取消专属读取、忽略迟到结果，但保留未发送草稿。主导航是独立于执行权限和持久显示密度的浏览状态。支持的产品路由通过 URL 在重新加载后恢复；无效来源地址明确报错，不自动选择另一个 Session。被卸载的插件页面仍回退到 Chat。

Work 展示当前 Session 的目标、执行、同步、待处理输入、执行关系和已记录变更。待处理入口打开该 Session 原有的对话，继续使用既有审批和提问控件；不会自动授权或回答。直接子级导航优先使用已有子 Agent 地址，子级可以返回父会话。后台 Job 保留不同状态语义；不把不活跃的子级显示为成功。页面不为不支持的执行类型伪造分发、重试或取消。

已记录变更来自 Host 的全会话 `deliverables` 投影，而不是已加载的聊天分页。它们是工具记录的路径，不是已验证的最终成果；历史采集缺失明确显示。打开操作向 [Host](../../host/work-results/README.md) 提交来源 Session 和精确路径；浏览器不改写相对路径，也不假定当前工作区拥有历史输出。工作区文件入口携带当前 Session 地址，surfaces 接收方拒绝与当前选中 Session 不一致的请求。

## 审阅与同步

执行、目标阶段、待处理输入和用户确认是独立事实。审阅已关闭的会话记录不要求先设置 Goal。Work 在同步且安静时先读取 `workResults/review`，然后才开放确认。Host 返回当前全部禁用原因，包括非根 Session、回合未关闭、排队输入、待处理交互或后台执行。读取失败时确认保持禁用，并提供重新核对入口。这些原因只解释当前观察；Host 在 maintenance 内重新校验实际写入。

确认绑定会话日志前缀，不证明测试通过、文件哈希、权限批准或全部子级完成。原始回执投影不证明持久化；确认展示要求已核验且仍有效的记录切片，其已确认修订与当前投影一致。打开输出或确认记录还要求 Connection 已同步、历史窗口已打开且未移除。断线、同步、历史错误或移除时保留旧事实供阅读，但禁止这些操作。核验和操作响应属于 Session、握手 epoch 与页面激活生命周期；其中任一改变都会作废迟到响应。重连不会重发写入。

Work 页面还以只读徽章展示最近一次已记录的内容审核，数据来自 `workResults/contentReview`：展示的是逐版本 currency 中最差的状态（`matches-confirmed`、`changed-unreviewed` 或 `not-reverified`），首次审核之前或读取失败时不显示徽章。本页面不负责提交内容审核。

## 资源库与显示密度

Library 跨既有 Session 分页搜索执行记录的输出，不扫描设备文件，也不激活冷会话。每行可以打开来源输出或显式进入来源对话。文件与知识和能力与连接分开呈现，文案说明哪些操作使用当前 Session。

采集缺失和不可读 Session 的提示跨分页保留。数字覆盖范围仍是本页，因为一个 Session 可以跨多个分页；最终游标不会消除此前缺口。失败页重试保留已提交查询和游标，重新搜索则替换扫描。重连或重新激活页面后，从第一页重读已提交查询，并保留尚未提交的搜索草稿；新扫描返回前禁用旧 epoch 的结果行。读取失败与原生打开失败独立处理。

详细视图只控制高级配置和诊断，不控制执行权限；持久化 `simple` 和 `developer` 值不变。简洁显示隐藏模型、预设、插件和轨迹控件，但保留证据检查。模式重读等待本地待定写入结束；销毁作废代次并阻止迟到的原生配置镜像。

## 模型体验

### 不直接请求模型

#### 模型看到什么

此包不产生模型输入。产品导航与投影读取既有 `session/queue` 与投影快照，不提交模型请求；显式继续对话使用其既有输入路径。

#### Token 影响

浏览与导航消耗零 token，切换视图不追加 Session 事件。

#### KV Cache 影响

无。显示密度不改变模型历史或工具权限。

## 已知限制与延期工作

- Work 描述选中 Session 及其直接执行关系，不是穷尽所有工作区的任务收件箱，也没有独立持久化 Task 实体。
- 确认绑定对话记录。成果版本、自动测试证明和整棵子 Agent 树验收需要单独的领域支持。
- Library 没有工作区筛选，原生输出打开仍受 Host 能力和授权约束。
- 产品模式尚无 Host 推送事件；本地成功写入和重连读取更新浏览器。
