# Agent Note: 独立工作事实与资料库缺失信息保留

Status: implemented

[English](2026-09-10-work-facts-library-coverage.md) | 中文

## 问题

Goal 阶段不能决定 Agent 或后台 Job 是否正在运行、人类输入是否待处理，以及结果是否已审核。单一完成标签会隐藏“Goal 已暂停但 Job 仍运行”等有效组合。资料库的多个分页可能重复扫描同一个 Session，所以页面计数不能累加为完整语料覆盖；最终页面正常也不能证明此前不可读的 Session 或未采集产物已经修复。

## 决定

现有当前 Session 工作投影独立发布执行状态与 Goal 阶段。已加载对话或可见 Job 列表报告活动时为运行中；对话快照存在且没有活动执行时为空闲；缺少该快照时为未知。审批和问题计数保持独立。失败与被终止的 Job 数只描述当前列表，不推断整个任务的结果。执行状态未知时不提供审核数据，也不能确认。页面展示作用域、待处理输入和可审核记录，即使没有 Goal 也如此；确认仍使用现有基于修订号的 Host API 与持久化核验。

资料库按来源 Session 与精确记录路径组成的键累积产物。它以布尔事实保留任一成功页面报告过的采集缺失或不可读 Session。数值计数只对应最新页面；客户端不累加计数，也不虚构独立 Session 总量。最终游标与任一保留的缺失同时存在时，结果明确标为不完整。重试失败页面保留已提交查询和游标；明确重新检索或提交新搜索时丢弃累积结果与缺失标记。读取错误与原生打开错误独立处理，请求代次阻止迟到回复污染新结果。

## 考虑过的替代方案

**扩充单一完成枚举。** 这仍然强迫正交状态服从优先级，混淆 Goal 意图、执行与审核。独立事实能够保留同时存在的状态，而不另建任务状态机。

**累加页面计数或相信最后一页。** 同一 Session 可以跨多个路径分页，使累加计数产生误导。只报告最后一页会丢失此前缺失。保留布尔缺失事实能够准确表达客户端所知，而不更改 Host 传输格式。

**同时替换主布局。** Chat 插槽所有者控制子注册与草稿生命周期。在缺少组装后浏览器验证时迁移导航，会把这些正确性修复与另一个独立高风险改动耦合。Work 与 Library 仍为侧栏页面。

## 影响

没有引入新的 Host 方法、Session 事件、持久化存储、能力注册表或依赖。仅类型导出的工作摘要使用 execution 字段替代聚合完成字段，消费者与测试夹具同步修改。缺失执行数据时采取保守策略，但该字段不保证连接数据的新鲜度。跨工作区管理与主区域导航属于后续独立工作。

## 验证

投影回归覆盖 Goal 与 Job 同时存在的状态、缺失绑定、无 Goal 的审核、仅执行结果变化、作用域切换，以及未改变的流式快照。扫描回归覆盖来源去重、缺失保留、重置语义和不可累加的页面计数。组件回归覆盖审核准入、同一修订的持久化重试、失败页恢复、重新检索与既有迟到回复行为。组装后的浏览器快照、完整客户端类型检查与覆盖率仍是发布所需证据；隔离 Node 断言运行不能替代这些检查。
