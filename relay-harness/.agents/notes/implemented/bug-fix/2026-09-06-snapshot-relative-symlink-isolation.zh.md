# Agent Note：快照相对符号链接隔离

Status: implemented

[English](2026-09-06-snapshot-relative-symlink-isolation.md) | 中文

## 问题

使用默认文件系统复制选项复制 ACP 快照工作区时，相对符号链接会被改写为指向源 checkout。指令链接因此离开生成的工作区，指令读取器会正确拒绝它。这也让原本应隔离的 fixture 依赖可变源文件。

## 决策

[快照 harness](../../../../packages/test-support/acp-snapshot/src/harness.ts)逐字复制符号链接文本。相对链接以复制后的工作区为基准解析；绝对链接保留显式目标，仍受读取器允许根目录策略约束。不放宽任何读取边界。

## 验证

POSIX 回归创建相对指令链接，检查复制后的链接文本，修改复制目标，并验证链接读取副本而源文件保持不变。组装后的指令快照保留基线发现、嵌套指令、压缩恢复和分隔符转义断言。

## 曾考虑的替代方案

解引用所有链接会丢失 fixture 的链接语义。将源 checkout 加入另一个指令根目录会破坏隔离并掩盖复制缺陷。以缺失指令的 transcript 刷新预期会删掉待测行为。

## 影响

Fixture 测试的是符号链接行为，而非解引用替代物。创建符号链接的回归仅在 POSIX 运行，因为 Windows 需要额外权限；普通工作区复制测试仍可跨平台运行。
