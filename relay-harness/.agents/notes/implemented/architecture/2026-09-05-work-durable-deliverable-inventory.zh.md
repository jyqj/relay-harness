# Agent Note：Work 使用执行时记录的全会话交付文件

Status: implemented

[English](2026-09-05-work-durable-deliverable-inventory.md) | 中文

## Problem

分页聊天不是任务索引：重新打开长 Session 后，早期交付文件会从 Work 消失。每次流式更新遍历全部已加载 Turn 也会发布内容未变的摘要。已完成 Goal 可能与正在执行的工作并存，文件打开被拒绝时需要用户可见的恢复入口。

## Decision

工具运行时从成功根调用所绑定定义的 `diff` 或 `generic/edit` 位置采集可选的 `ToolExecutionSuccess.producedFiles`。Agent 循环把冻结路径复制到 `tool/result`，不加入模型内容。空数组表示已采集但没有声明文件，缺失表示旧记录或采集不可用。可选呈现器失败不能把已完成变更转为失败且可重试的执行。Session 恢复时验证采集路径数组，仅改写内容的操作必须保留此字段。

既有 ui-deliverables Host 侧注册全日志纯 `deliverables` 投影，发布按首次出现顺序去重的路径和 `unindexedResults`，忽略失败结果与 surface 改写，不相关事件保持状态引用不变。它不会使用当前已安装的呈现器重建旧采集结果。既有[本轮文件链接决策](../feature/2026-07-31-web-workspace-file-links.md)继续适用于 Turn 收尾；此索引是同一持久来源的全会话读模型，不是另一个 Session 状态所有者。

Work 读取该投影，提示采集不完整或不可用，并将轨迹计数标为已加载记录。执行或后台任务运行中时优先于 Goal 完成，暂停与受阻阶段明确展示。输入和派生事实相等时保持可观察对象引用。Host 打开错误提供重试与关闭，并按 Session 屏蔽迟到结果。

## Alternatives considered

**从浏览器时间线派生索引。** 分页与重新挂载会改变答案，并迫使系统重复扫描历史。

**通过当前工具注册表回放旧调用。** preset 定义或呈现器变化会改写历史产出声明，纯投影也会依赖可变运行时配置。

**追踪全部文件系统副作用。** shell 与嵌套 Code Mode 变更审计需要更广的执行协议。声明的根工具位置是更窄且明确的范围，不能证明文件仍存在或任务通过独立验收。

## Consequences

模型内容与请求 schema 不变。历史成功记录未采集时保持可见的不完整状态，不静默编造结果。既有投影传输与 SDK 事件载体透传新增数据。测试覆盖成功采集、呈现器失败、冻结结果替换、真实 AgentLoop 日志、超出首个分页范围的完整日志恢复、空与缺失采集区分、非法持久输入、暂停／受阻及完成与运行并存状态、无变化流式通知、迟到打开错误和两个 SDK 的子进程载体。组装 Web 回放场景覆盖分页、重载与 Host 拒绝，运行需要最新构建的客户端产物。
