# External Relay Scheduling Interface

English | [中文](README.zh.md)

Relay scheduling is an independent project. This directory describes only the agent's qualitative requirements, responsibility boundary, and versioned interface:

- [`overview.md`](overview.md): capabilities scheduling must provide;
- [`interface.md`](interface.md): HTTP/JSON + SSE contract.

This directory does not define scheduling scores, benchmark mapping, cost weights, model-pool implementation, or operating weights.
